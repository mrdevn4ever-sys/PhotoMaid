# App Review Notes (App Store Connect › App Review Information › Notes)

---

Arrumo works entirely on the device. No account, no login, no own server, no cloud upload. (Former working name: PhotoMaid, still visible in the bundle ID.) Please allow Photos access (Full Access recommended; Limited Access also works). A few photos and videos in the library are enough to test.

MAIN FEATURES
1. Swipe to clean up (Today > "Start cleaning up"), one item at a time: up = Keep, left = Arrumo Trash (nothing deleted), right = Later (returns after 2 days), down = previous item. Undo, favorite, share, add to album and edit sit below each item. Directions can be changed in Settings > Swipes & buttons.
2. Deleting happens only when the user opens Trash and confirms. iOS then shows its own system dialog; items go to "Recently Deleted" in Photos. The app never deletes anything automatically.
3. Clean up tab: photos, videos, screenshots, months, large files (sizes measured on device), exact duplicates, photo series, collections, folders connected via the Files app, and on-device Apple Vision analysis (blurry, similar, photos with text, by subject). Results are suggestions only.
4. Photos tab: timeline, albums and folders of the Photos app, favorites, search, selection, viewer, slideshow, own tags and notes.
5. Studio tab: photo and video editor (saves a new copy by default), collage, movie, resize/convert/remove location, GIF, PDF from photos, document scanner, PDF tools, backup to a folder chosen in Files.
6. History tab: past decisions, Later list (optional reminder notifications), progress.
7. Games with the user's own photos: Pairs, Photo Snake, Photo Blocks (Today, or "Take a break" while swiping).

PRIVATE VAULT (code-protected, encrypted area)
- Open: Today > gear icon (top right) > Privacy & data > Private vault. Setup: 6-digit PIN (any digits, e.g. 123456) or password; Face ID optional; recovery key optional (can be skipped); "Hide entry" optional.
- Second entry: press and hold the "Arrumo" title at the top of Today for 2 seconds (the dial in place of the final "o" turns). With "Hide entry" on, the Settings row disappears and only this gesture opens the vault. Settings explains this right below the vault row.
- "Add to vault" copies the chosen photos/videos into the vault, verifies them, then iOS asks in its own dialog whether to delete the originals from Photos. "Move back to Photos" restores them. Also inside: folders, files from the Files app, notes, voice notes, document scan, and editing tools whose results stay in the vault.
- Security: AES-GCM encryption on the device, key in the Keychain, optional Face ID. Locks as soon as the app goes to the background and is hidden in the app switcher. Nothing is uploaded; included in the user's encrypted iPhone backup. No server-side recovery: without code, Face ID or the optional recovery key the content cannot be opened. The app states this during setup.

FREE VERSION AND ADS
All tools are free. Free allows 100 deletions per day, +100 once a day after an optional rewarded video. Google AdMob ads: Google's consent form (UMP) first, then the App Tracking Transparency prompt, before any ad request. Formats: app-open ad from the 4th launch, a labeled native ad card after every 50 swipe decisions (never counted as a decision), optional rewarded videos (extra deletions, additional vault folders). Ad requests never contain photos, file names or media identifiers.

IN-APP PURCHASE
Arrumo Pro (one-time, non-consumable): no ads, unlimited deletions, vault folders without videos. Restore: Settings > Arrumo Pro > Restore purchases.

PERMISSIONS
Photos (core). Camera: document scan only. Microphone: vault voice note only. Face ID: vault only, optional. Notifications: optional Later reminders. Tracking: ad personalization, free version only.
